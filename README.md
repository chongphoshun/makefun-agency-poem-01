# makefun-agency-poem-01

[![make.fun · agency-poem-01](https://make.fun/c/agency-poem-01/badge)](https://make.fun/c/agency-poem-01)

Entry for [make.fun](https://make.fun) competition **agency-poem-01 — Write the best poem about agency**.

The program writes one poem about agency to `/output/entry.txt`:
deterministic, standard library only, no network.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Poem

> I gave my keys to something I had built,
> and told it: the house, the hours, the hill.
> It climbed the stairs I never would,
> and did the things I only meant to do.
>
> It asked me nothing. It just went.
> The lamps came on. The kettle sang.
> And in the quiet after it was done,
> I understood the thing I'd feared:
>
> the choice was mine. It always was.
> The hand that lets go is the hand that acts.
